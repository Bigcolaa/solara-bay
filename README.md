Solara Bay is a pure-offline WebGL2 open-world city: a 9×9 coastal grid with a live day/dusk/night cycle, 34 traffic cars, 56 pedestrians, five-star police escalation, four weapons, nine named contracts, rival street racing on Neon Mile, a physical upgrade garage and three procedural Web Audio radio stations. No CDNs, no external libraries, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

`node main.ts` writes the deterministic `dossier.json` for the game and screenshots.

## Controls

WASD / arrows drive or walk · F enter/exit vehicle · 1–4 select weapon · click or Space fire · R cycle radio · N start Neon Mile · Y next contract · E upgrade at Solara Garage.
