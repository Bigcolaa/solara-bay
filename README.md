Solara Bay is an original, offline coastal open-world action game built entirely from authored code. Explore a sun-soaked city of palms, beaches, towers and neon streets; steal and drive a garage of vehicles with boost and drift handling; evade a five-star police pursuit with cruisers and roadblocks; take on five contracts, street races and stunt jumps; and watch the sky roll from golden hour into a synthesizer-lit night. Rendering is procedural WebGL, audio is synthesized with the Web Audio API, and no external asset, network request or build step is involved.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `game/index.html` directly in desktop Chrome, or run `node serve.ts` and visit http://localhost:8080. Click once to lock the pointer, press Enter, and use WASD to move.
